* Current model is based on LSTM neural networks which uses 40 alphas as features from "101 formulaic alphas".
* To run the model you need to give directory of csv file of the stock in feature_generator.py then run the code which will generate a csv file.
* Run strategy.py to visualize the results of the strategy.
